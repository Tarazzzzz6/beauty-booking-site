# Пілотний запуск — чеклист підключення першого салону

Мета: один реальний салон/майстер у Монреалі повністю проходить шлях клієнта і салону наживо. Орієнтовний час: 15–20 хвилин + тестове бронювання.

## Перед стартом (власник платформи)
- [ ] Воркер v4 задеплоєний (див. SETUP-OWNER.md), бот @pershe1012_bot відповідає на `/myid`.
- [ ] Сайт bookingclub.beauty відкривається, каталог на місці.
- [ ] (Опційно) Cron Trigger щогодини для нагадувань; Stripe — лише якщо салон хоче депозит онлайн.

## Крок 1. Заявка салону
- [ ] Салон заповнює форму **bookingclub.beauty/join**: назва, адреса/район, послуги, мови, тариф, Telegram ID.
- [ ] Заявка прийшла власнику в Telegram (тип `salon_join`).
- Якщо салон не знає свій Telegram ID: хай напише боту **@pershe1012_bot** команду `/myid` — бот відповість номером. Цей номер має збігатися з полем Telegram ID у заявці.

## Крок 2. Додати салон у каталог
- [ ] У `data.js` додати/оновити лістинг салону: `id`, `name`, `address`, `lat/lng`, `phone`, `services` (serviceId + ціни from/to + durationMin), `images`.
- [ ] **Обовʼязково:** `telegramChatId: "<ID із заявки>"` — без цього бронювання летітимуть тільки власнику платформи, а не салону.
- [ ] За бажанням: `schedule` (робочі години за днями тижня), `partner: true` для Partner-тарифу.
- [ ] Запушити в main → Cloudflare Pages сам задеплоїть сайт (~1 хв). Перевірити: картка салону зʼявилась на головній і в профілі.

## Крок 3. Тестове бронювання (разом із салоном)
- [ ] Власник/знайомий бронює послугу цього салону на сайті (реальний слот).
- [ ] Салону в Telegram прийшло повідомлення про бронювання з кодом **BK-XXXXXX**. Копія — власнику платформи.
- [ ] Після бронювання натиснути на сайті кнопку **«📲 Підтвердження і нагадування в Telegram»** (відкриється бот) → Start → бот підтвердив запис. (Це тестує клієнтський шлях.)
- [ ] Салон у боті: `/bookings` — запис у списку.
- [ ] Слот на сайті у цю дату/час зник для інших клієнтів (перевірити картку салону).
- [ ] Салон тестує графік: `/close <завтра>` → на сайті на цю дату слотів нема; `/open <завтра>` → слоти повернулись.
- [ ] Скасування: салон `/cancel BK-XXXXXX` на тестовому записі → слот знову вільний; клієнт (якщо підключався) отримав сповіщення про скасування.
- [ ] Кабінет: салон заходить на **bookingclub.beauty/admin**, отримує код у Telegram, бачить свої бронювання; міняє одну ціну → ціна оновилась у картці на сайті.

## Крок 4. Памʼятка салону (надіслати після підключення)
```
Вітаємо в Booking Club! 💎
Ваші бронювання приходитимуть сюди, у цей чат з ботом.

Команди бота:
• /bookings — найближчі записи клієнтів
• /cancel BK-XXXXXX — скасувати запис (код є у повідомленні про бронювання)
• /close 2026-11-03 — закрити день (вихідний, відпустка)
• /open 2026-11-03 — відкрити день назад
• /closed — список закритих днів

Кабінет (бронювання, графік, ціни): bookingclub.beauty/admin
Вхід — за кодом, який бот надішле у цей чат.

Клієнтам після запису радимо натискати на сайті кнопку
«Підтвердження і нагадування в Telegram» — тоді бот сам нагадає
їм про візит за день і за 2 години.

Питання — до власника платформи або на hello@bookingclub.beauty
```

## Крок 5. Після пілота
- [ ] Зібрати від салону: чи зручно, чого бракує (нагадування? відповіді клієнтам?).
- [ ] Перевірити статистику: скільки реальних бронювань за перший тиждень.
- [ ] Вирішити про Stripe-депозит (якщо були no-show) і підключення наступних салонів.
