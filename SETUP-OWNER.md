# Активація бота v2 — інструкція власника (5–7 хвилин)

Навіщо: щоб бронювання летіли **напряму кожному салону** в його Telegram, а салони самі керували графіком командами боту (`/close`, `/open`). Код уже готовий (worker.js v2 у цьому репозиторії) — треба лише вставити його у Cloudflare і додати три налаштування.

## Крок 1. Новий токен бота
1. Telegram → **@BotFather** → `/mybots` → твій бот → **API Token** → **Revoke current token** (старий був у публічному коді — його обовʼязково відкликати).
2. BotFather покаже новий токен — скопіюй, нікому не надсилай у чатах.

## Крок 2. Секрет у Cloudflare
1. dash.cloudflare.com → **Workers & Pages** → воркер **snowy-shadow-0b58**.
2. **Settings → Variables and Secrets → Add**:
   - `BOT_TOKEN` = новий токен, тип **Secret**.
   - `CHAT_ID` = твій Telegram ID (дізнатись: напиши боту **@userinfobot**), тип Text. Сюди падатимуть копії всіх бронювань і заявки салонів.

## Крок 3. Сховище графіків (KV)
1. У Cloudflare: **Storage & Databases → KV → Create namespace** → назва `booking-club`.
2. Відкрий воркер → **Settings → Bindings → Add → KV namespace**: імʼя змінної **`BC_KV`**, namespace — `booking-club`.

## Крок 4. Код воркера
1. Воркер → **Edit code** → видали весь старий код → встав код із файлу **worker.js** цього репозиторію → **Deploy**.

## Крок 5. Webhook (щоб бот відповідав на команди)
Відкрий у браузері (підстав свій токен і адресу воркера):
```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://snowy-shadow-0b58.irafarm2000.workers.dev
```
Має відповісти `{"ok":true,"result":true,"description":"Webhook was set"}`.

## Крок 6. Перевірка
1. Напиши своєму боту `/myid` — він відповість твоїм ID і списком команд.
2. Напиши `/close 2026-12-25` — бот підтвердить закриття дня.
3. Зроби тестове бронювання на сайті — повідомлення має прийти тобі (копія). Коли у салону в каталозі буде заповнений його `telegramChatId`, бронювання полетить і салону напряму.

## Як підключати салони після цього
1. Салон заповнює **bookingclub.beauty/join** (там є поле Telegram ID і підказка, як його дізнатись).
2. Заявка приходить тобі в Telegram з усіма даними.
3. Додаєш салон у `data.js` (поля: контакти, послуги, `telegramChatId` із заявки, за бажанням `schedule` — робочі години) — або скажи мені (Muse), я додам.
4. Салон керує вихідними сам: команди боту `/close ДАТА`, `/open ДАТА`, `/closed` — сайт підтягує закриті дні автоматично.

## Якщо щось пішло не так
- Бронювання падає з помилкою 500 → не додано секрет `BOT_TOKEN` (крок 2).
- Бот не відповідає на команди → не встановлено webhook (крок 5) або у Bindings немає `BC_KV` (для /close).
- Сайт: перевірити, що воркер живий — відкрий адресу воркера у браузері, має показати `OK`.

# Оновлення v4 — кабінет, клієнтські сповіщення, Stripe

Після заміни worker.js на версію v4 (крок 4 вище — Edit code → вставити новий код → Deploy) увімкнуться описані нижче можливості. Частина працює одразу, Stripe — після додавання ключів.

## Клієнтські сповіщення і нагадування (працює одразу після деплою v4)
- Після бронювання сайт показує клієнту кнопку **«📲 Підтвердження і нагадування в Telegram»** — це deep link на бота з кодом бронювання.
- Клієнт натискає Start у боті → бот привʼязує його чат до запису, надсилає підтвердження (салон, послуга, дата, час) і далі сам шле **нагадування за ~24 год і за ~2 год** до візиту (час Монреаля).
- Клієнт може скасувати власний запис командою `/cancel BK-XXXXXX` прямо в боті — салон отримає сповіщення про скасування. Салон, скасовуючи запис, так само сповіщає клієнта.
- **Опційно (для точності нагадувань): Cron Trigger.** Воркер → **Settings → Triggers → Cron Triggers → Add**: розклад `0 * * * *` (щогодини). Без крону нагадування все одно працюють, коли хтось відкриває `https://snowy-shadow-0b58.irafarm2000.workers.dev/remind` (той самий scan, ідемпотентний).

## Кабінет салону (працює одразу після деплою v4)
- Сторінка: **bookingclub.beauty/admin**
- Салон вводить свій Telegram ID → бот шле 6-значний код → вхід, сесія 30 днів.
- У кабінеті: список бронювань (ті самі, що в боті), закриті дні (той самий графік, що й команди `/close`/`/open`) і **редагування цін** — ціни зберігаються на сервері й одразу діють на сайті для всіх.
- Умова: у салону має бути вписаний `telegramChatId` у його картці в `data.js` (щоб кабінет знав, який це лістинг). Бронювання і графік працюють і без цього.

## Stripe — депозит $10 CAD (коли будеш готовий)
На сайті вже є чекбокс «Депозит проти no-show — $10». Поки Stripe не підключено, сайт чесно пише, що депозит — на місці в салоні. Щоб увімкнути онлайн-оплату:

1. Зареєструй акаунт на **stripe.com** (бізнес у Канаді, валюта CAD), пройди верифікацію.
2. У Stripe Dashboard → **Developers → API keys** → скопіюй **Secret key** (`sk_live_...`; для першого тесту можна `sk_test_...`).
3. Cloudflare → воркер **snowy-shadow-0b58** → **Settings → Variables and Secrets → Add**:
   - `STRIPE_SECRET_KEY` = секретний ключ, тип **Secret**.
4. У Stripe Dashboard → **Developers → Webhooks → Add endpoint**:
   - URL: `https://snowy-shadow-0b58.irafarm2000.workers.dev/stripe/webhook`
   - Подія: **`checkout.session.completed`**
   - Після створення Stripe покаже **Signing secret** (`whsec_...`).
5. У Cloudflare додай другий секрет воркера: `STRIPE_WEBHOOK_SECRET` = `whsec_...`, тип **Secret**.
6. Перевірка: зроби тестове бронювання на сайті з увімкненим депозит — після підтвердження зʼявиться кнопка **«💳 Оплатити депозит $10 онлайн»**. Після оплати салону і тобі прийде в Telegram: «💰 Депозит $10 оплачено (BK-…)».

Гроші йдуть напряму на твій Stripe-акаунт (платформа комісії з депозиту не бере). Повернення депозиту клієнту (якщо візит відбувся і салон так вирішив) — вручну в Stripe Dashboard → Payments → Refund.

# Оновлення v5 — самопідключення салонів і облік відвідуваності

Після заміни worker.js на версію v5 (той самий крок: Edit code → вставити новий код → Deploy) салони підключаються САМІ — без ручного редагування data.js. Сайт підхоплює нові салони автоматично (Cloudflare Pages деплоїти не треба — сайт сам тягне список із воркера).

## Бот-майстер підключення (головна новинка)
- Салон відкриває бота **@pershe1012_bot** і тисне **/join** (або переходить за лінком `t.me/pershe1012_bot?start=join` — такий лінк уже стоїть на сторінці bookingclub.beauty/join).
- Бот покроково питає: назва → тип (салон / майстер на дому / барбершоп) → адреса чи район (для майстрів на дому публічно показується ТІЛЬКИ район — бот це пояснює) → послуги кнопками з каталогу (можна кілька) → ціна за кожну послугу → години роботи (вільним текстом, напр. «Пн–Пт 10–19, Сб 11–17, Нд — вихідний») → мови → **фото** (1–6 штук прямо в чат) → підсумок → «Надіслати заявку».
- Заявка приходить **тобі** в Telegram із підсумком і кнопками **✅ Опублікувати / ❌ Відхилити**. Тиснути може тільки власник платформи.
  - **✅** → салон миттєво зʼявляється на bookingclub.beauty (картка з бейджем «🆕 Новий», профіль, карта, бронювання, графік і кабінет працюють одразу). Салону бот шле вітання з лінком на його профіль.
  - **❌** → заявка видаляється, салону приходить ввічливе повідомлення, що можна уточнити дані й подати ще раз.
- Заявка з форми на **bookingclub.beauty/join** тепер працює так само: створюється заявка, тобі приходить повідомлення з тими самими кнопками ✅/❌ (фото через форму додати не можна — для фото є бот).

## Динамічні лістинги — як це влаштовано
- Опубліковані салони живуть не в коді сайту, а у KV воркера. Сайт при завантаженні тягне їх через `GET /listings` і додає до каталогу.
- Фото салонів зберігаються в Telegram: сайт показує їх через проксі воркера (`/photo/…`). Нічого додатково налаштовувати не треба.
- У динамічного салону немає рейтингу, поки немає відгуків, — сайт показує бейдж **«🆕 Новий»** замість зірок.
- Координати для карти сайт визначає за районом (таблиця районів Монреаля в data.js).
- Бронювання на динамічний салон іде прямо в його Telegram (chatId салону зберігається автоматично) — календар, нагадування клієнтам і кабінет працюють так само, як у «старих» салонів із data.js.

## Облік відвідуваності (база по кожному салону)
- Після кожного візиту (через ~30 хв після його часу) бот питає салон: «Клієнт N, послуга, дата/час — прийшов?» з кнопками **✅ Прийшов / 🚫 Не прийшов**. Питає один раз.
- Салон може відмітити і вручну: `/done BK-XXXXXX` — прийшов, `/noshow BK-XXXXXX` — не прийшов.
- Про кожен **no-show** бот додатково повідомляє **тебе** (хто, який салон, коли).
- **`/stats`** (тільки власник): по кожному салону — всього записів, ✅ прийшло, 🚫 no-show, 🔜 майбутніх.
- Та сама таблиця є у **кабінеті власника** (bookingclub.beauty/admin → блок «Платформа · всі салони») — видно тільки коли ти залогінений своїм Telegram ID. У записах салону статуси теж видно бейджами «✅ клієнт прийшов» / «🚫 no-show».

Нові команди бота:
- `/join` — підключення салону (майстер із фото)
- `/done BK-XXXXXX` / `/noshow BK-XXXXXX` — відмітити візит
- `/stats` — статистика платформи (тільки власник)
