# Активація бота v2 — інструкція власника (5–7 хвилин)

Навіщо: щоб бронювання летіли **напряму кожному салону** в його Telegram, а салони самі керували графіком командами боту (`/close`, `/open`). Код уже готовий (worker.js v2 у цьому репозиторії) — треба лише вставити його у Cloudflare і додати три налаштування.

## Крок 1. Новий токен бота
1. Telegram → **@BotFather** → `/mybots` → твій бот → **API Token** → **Revoke current token** (старий був у публічному коді — його обовʼязково відкликати).
2. BotFather покаже новий токен — скопіюй, нікому не надсилай у чатах.

## Крок 2. Секрет у Cloudflare
1. dash.cloudflare.com → **Workers & Pages** → воркер **snowy-shadow-0b58**.
2. **Settings → Variables and Secrets → Add**:
   - `BOT_TOKEN` = новий токен, тип **Secret**.
   - `CHAT_ID` = твій Telegram ID (дізнатись: напиши боту **@userinfobot**), тип Text. Сюди падатимуть копії всіх бронювань і заявки салонів.

## Крок 3. Сховище графіків (KV)
1. У Cloudflare: **Storage & Databases → KV → Create namespace** → назва `booking-club`.
2. Відкрий воркер → **Settings → Bindings → Add → KV namespace**: імʼя змінної **`BC_KV`**, namespace — `booking-club`.

## Крок 4. Код воркера
1. Воркер → **Edit code** → видали весь старий код → встав код із файлу **worker.js** цього репозиторію → **Deploy**.

## Крок 5. Webhook (щоб бот відповідав на команди)
Відкрий у браузері (підстав свій токен і адресу воркера):
```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://snowy-shadow-0b58.irafarm2000.workers.dev
```
Має відповісти `{"ok":true,"result":true,"description":"Webhook was set"}`.

## Крок 6. Перевірка
1. Напиши своєму боту `/myid` — він відповість твоїм ID і списком команд.
2. Напиши `/close 2026-12-25` — бот підтвердить закриття дня.
3. Зроби тестове бронювання на сайті — повідомлення має прийти тобі (копія). Коли у салону в каталозі буде заповнений його `telegramChatId`, бронювання полетить і салону напряму.

## Як підключати салони після цього
1. Салон заповнює **bookingclub.beauty/join** (там є поле Telegram ID і підказка, як його дізнатись).
2. Заявка приходить тобі в Telegram з усіма даними.
3. Додаєш салон у `data.js` (поля: контакти, послуги, `telegramChatId` із заявки, за бажанням `schedule` — робочі години) — або скажи мені (Muse), я додам.
4. Салон керує вихідними сам: команди боту `/close ДАТА`, `/open ДАТА`, `/closed` — сайт підтягує закриті дні автоматично.

## Якщо щось пішло не так
- Бронювання падає з помилкою 500 → не додано секрет `BOT_TOKEN` (крок 2).
- Бот не відповідає на команди → не встановлено webhook (крок 5) або у Bindings немає `BC_KV` (для /close).
- Сайт: перевірити, що воркер живий — відкрий адресу воркера у браузері, має показати `OK`.
